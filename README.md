Projeto Lanchonete em C
=======================

🍔 Este projeto simula o funcionamento de uma lanchonete utilizando a linguagem C.
O sistema permite gerenciar pedidos, cardápio e clientes de forma simples e prática.

------------------------------------------------------------
🚀 Funcionalidades
- Cadastro de produtos (nome, preço, código).
- Exibição do cardápio.
- Realização de pedidos.
- Cálculo automático do valor total.
- Registro de clientes.
- Relatórios de vendas.

------------------------------------------------------------
🛠️ Tecnologias Utilizadas
- Linguagem: C
- Compilador: GCC ou equivalente
- Sistema Operacional: Windows/Linux

▶️ Como Executar
1. Clone o repositório:
   git clone [https://github.com/seu-usuario/lanchonete-c.git](https://github.com/Leonidiojr/Faculdade_C.git)

2. Compile o projeto:
   gcc src/*.c -I include -o lanchonete

3. Execute:
   ./lanchonete
